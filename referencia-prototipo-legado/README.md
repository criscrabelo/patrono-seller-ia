# Protótipo legado — não faz parte da aplicação

Estes arquivos (`patrono-app.jsx`, `screens-*.jsx`, `data*.jsx`, os `.html`)
são o protótipo de alta fidelidade em React+Babel que serviu de referência
visual para o design aprovado. Confirmado por busca no código: **nenhum
arquivo em `app/`, `components/`, `lib/` ou `hooks/` importa nada daqui**.

A aplicação real (Next.js + Prisma + Postgres, em `app/`) é o produto em
produção. Este material fica preservado apenas como referência histórica
do design — não deve ser executado nem editado como parte do produto.

Movido para cá em 13/09/2026 (P0 do MVP Afiliada) para tirar 28 arquivos
sem uso do build da raiz do repositório, sem perder o histórico (git mv).
