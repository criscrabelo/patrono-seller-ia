Quem faz o quê

A conexão tem duas partes: o cadastro do app (só você pode fazer, é da sua conta TikTok) e o código (Claude Code implementa no repo).

A Content Posting API do TikTok exige aprovação do app (pode levar dias). Por isso a plataforma já nasce com o modo Pacote Manual — você publica na mão hoje e liga o automático quando a API for liberada. A tela Publicação · TikTok do protótipo mostra os dois modos.
01

O que você faz no portal do TikTok

  1. 1
    Crie uma conta em developers.tiktok.com e registre um app (Manage apps → Connect an app).
  2. 2
    Adicione os produtos Login Kit e Content Posting API ao app. Para marcar produtos: TikTok Shop (à parte, via TikTok Shop Partner Center).
  3. 3
    Configure o redirect URI: https://SEU-DOMINIO/api/integracoes/tiktok/callback (e a versão localhost para testes).
  4. 4
    Solicite os escopos user.info.basic, video.upload, video.publish. Publicação direta exige revisão do app pelo TikTok.
  5. 5
    Copie o Client Key e o Client Secret e mande para as variáveis de ambiente (próxima seção). Nunca exponha o Secret no frontend.

Variáveis de ambiente — .env

TIKTOK_CLIENT_KEY=awxxxxxxxxxxxx
TIKTOK_CLIENT_SECRET=••••••••••••••••
TIKTOK_REDIRECT_URI=https://app.patronoseller.com/api/integracoes/tiktok/callback
NEXTAUTH_URL=https://app.patronoseller.com
02

Fluxo de login (OAuth · Login Kit)

O que o Claude Code implementa para o botão "Conectar TikTok" da tela de Publicação.

1
Usuária clica "Conectar TikTok"
Redireciona para https://www.tiktok.com/v2/auth/authorize com client_key, scope, redirect_uri e state.
2
TikTok devolve um code
No callback, troca por token: POST /v2/oauth/token/ → access_token + refresh_token.
3
Salva os tokens (cifrados)
No model Integracao do Prisma. O access_token expira em ~24h — renovar com o refresh_token.
4
Conta conectada
A tela passa a mostrar @conta, escopos e validade (igual ao protótipo).

prisma — model Integracao

model Integracao {
  id String @id @default(cuid())
  provider String        // tiktok | tiktok_shop | shopee ...
  contaExterna String?   // @patrono.organiza
  accessToken String     // CIFRAR em repouso
  refreshToken String?
  expiraEm DateTime?
  escopos String[]
  status String          // conectado | expirado | revogado
  userId String          // dono da conexão
}
03

Publicar vídeo (Content Posting API)

Modo automático. Só roda depois do app aprovado e sempre passa pelo gate de aprovação na 1ª campanha.

// 1) inicia o upload
POST https://open.tiktokapis.com/v2/post/publish/video/init/
Authorization: Bearer {access_token}
{
  "post_info": {
    "title": "legenda + #hashtags",
    "privacy_level": "PUBLIC_TO_EVERYONE",
    "disable_comment": false
  },
  "source_info": {
    "source": "FILE_UPLOAD",
    "video_size": 1048576, "chunk_size": 1048576, "total_chunk_count": 1
  }
}
// 2) envia os bytes para a upload_url retornada (PUT)
// 3) consulta status:
POST /v2/post/publish/status/fetch/  → PROCESSING | PUBLISH_COMPLETE
Endpoint do repo: app/api/conteudos/[id]/publicar/route.ts (já existe — adaptar para chamar a API com o token salvo). O app/api/cron/publicar/route.ts dispara os agendados do calendário.
04

Pacote manual — funciona hoje

Enquanto a API não é aprovada, a plataforma gera um .zip pronto para postar. É o modo padrão na tela de Publicação.

Conteúdo do pacote (/api/conteudos/[id]/pacote)

📦 talheres_pov_v1.zip
 ├─ video.mp4          // criativo autorizado, 9:16
 ├─ legenda.txt        // legenda + CTA
 ├─ hashtags.txt       // até 5 hashtags
 ├─ link-afiliado.txt  // patrono.link/talheres
 └─ instrucoes.txt     // horário recomendado + passo a passo
  1. 1
    A usuária clica "Baixar pacote (.zip)" no card do próximo vídeo.
  2. 2
    Abre o TikTok, sobe o video.mp4 e cola legenda + hashtags.
  3. 3
    Marca como postado na plataforma → entra nos Relatórios e no Motor de Decisão.
05

Regras de segurança (não pular)

  • !
    Aprovação inicial obrigatória: a 1ª publicação automática de cada produto/campanha passa pelo painel "Aprovar Agora" antes de ir ao ar.
  • !
    Só criativo autorizado: o vídeo precisa estar na Biblioteca com podePostar = true. Nada de terceiros, sem remoção de marca d'água.
  • !
    Secret no servidor: Client Secret e tokens só no backend, cifrados. Nunca no bundle do Next.
  • !
    Link válido: bloquear publicação se o link de afiliado estiver quebrado ou o produto não vinculado.
  • !
    Renovação de token: agendar refresh antes de expirar; se revogado, marcar a integração como expirado e avisar.
Importante: a aprovação da Content Posting API e as políticas do TikTok mudam. Sempre confira a documentação oficial em developers.tiktok.com antes de publicar em produção.
